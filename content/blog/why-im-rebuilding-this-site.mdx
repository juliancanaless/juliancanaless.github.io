I built this site mostly for myself. Partly to have a portfolio that doesn't look like it was made in 2019, but mostly because I wanted a place to write things down that isn't a private note nobody ever sees.

I don't have an audience and I'm not pretending to. This is more like a public notebook. If someone stumbles across it and finds something useful, cool. If not, at least I have a record of what I was thinking about.

A few things I'll probably write about:

1. projects I learned from, especially the ones that didn't work
2. stuff I'm figuring out in ML, AI infra, and software
3. notes from books, courses, and work
4. whatever else I'm thinking about during this early-career phase

The site itself is Next.js + TypeScript with MDX for blog posts. Nothing groundbreaking. It's just nice to have a setup where adding a new post is "create a file and write" instead of fighting a CMS.

Posting schedule will be erratic. Some weeks I might post three times. Other stretches might be a month of crickets. That's just how it's going to be.

We'll see where it goes.
